# Companion Assets Structure

Each companion has three image variants:
- `profile/` - Main profile picture (used in list/detail cards)
- `v1/` - Cozy home office style (from companion-prompts.md V1)
- `v2/` - Sexy stylized style (from companion-prompts.md V2)

## Naming Convention
- Files: `{companion-id}-{variant}.{ext}`
- Example: `ava-profile.png`, `ava-v1.png`, `ava-v2.png`

## Supported Formats
- PNG (preferred for transparency)
- WebP (for web optimization)
- JPG (for photos)

## Dimensions
- Profile: 512x512px (square)
- V1/V2: 1024x1024px (square, for high-quality generation)
